# Retrial — challenge-gated NFT mint + marketplace

A mint site where **you must solve a proof-of-work challenge before you can mint**,
plus an escrow marketplace so minted NFTs can be traded.

- **Chain:** BNB Smart Chain (mainnet `56`, testnet `97`)
- **Supply:** 3000 NFTs, hard cap
- **Headline price:** FREE (gas only)
- **Actual on-chain mint fee:** `0.00008 BNB` + gas
- **Gate:** `keccak256(minter ‖ nonce)` must have at least N leading zero bits,
  verified **on chain** — no backend, no signing key, no way to skip it by
  calling the contract directly.

## Contracts

| Contract | Purpose |
|---|---|
| `contracts/RetrialNFT.sol` | ERC-721 (OpenZeppelin), `MAX_SUPPLY = 3000`, `MINT_FEE = 0.00008 BNB`, PoW-gated `mint(nonce)`, max 5 per wallet, one nonce usable once, on-chain SVG metadata. |
| `contracts/RetrialMarket.sol` | Escrow marketplace: `list` / `updatePrice` / `cancel` / `buy`, priced in BNB, `feeBps` 0 by default. |

Mint rules, in order: supply left → exact fee → per-wallet cap → nonce unused →
proof valid. `powValid(minter, nonce, bits)` is a public pure view so the frontend
can pre-check a solved nonce before spending gas.

## Layout

```
contracts/     RetrialNFT.sol, RetrialMarket.sol
test/          15 hardhat tests (real PoW solving, every revert path, market flows)
scripts/       deploy.js · mint-agent.js (BAW) · e2e-local.js (end-to-end proof)
web/           static site: index.html (mint) · market.html · solver-worker.js
SPEC.md        the product rules + build spec everything is graded against
```

## Quickstart

```bash
npm install
npx hardhat compile
npx hardhat test            # 15 passing
```

### Prove it end to end on a real chain

```bash
npx hardhat node                                        # terminal 1
npx hardhat run scripts/deploy.js --network localhost   # writes web/config.js
npx hardhat run scripts/e2e-local.js --network localhost
```

`e2e-local.js` solves the challenge, mints with the exact fee, decodes
`tokenURI`, approves + lists, buys from a second account, then proves the gate
still gates (replayed nonce reverts, missing fee reverts). Every number it prints
comes from a receipt.

### Open the site locally

```bash
cd web && python3 -m http.server 8099
# http://127.0.0.1:8099/index.html  ·  /market.html
```

`web/` is static — no bundler, no build step. `web/config.js` holds the chain and
contract addresses and is (re)generated by `scripts/deploy.js`.

## Deploy

```bash
cp .env.example .env      # fill PRIVATE_KEY (+ optional RPC / BscScan key)
npm run deploy:testnet
npm run deploy:mainnet
```

Measured gas: **RetrialNFT 2,014,654** + **RetrialMarket 1,136,576** = 3,151,230
gas for both. At BSC's 0.05 gwei floor that is **~0.00016 BNB** — so a mainnet
deploy needs roughly 0.0002 BNB in the deployer account. `DIFFICULTY_BITS` (default
16) sets the challenge difficulty at deploy time.

Deploy with a throwaway key and then hand ownership to the real wallet:

```bash
# after deploy, from the owner account
nft.transferOwnership(0xYourWallet)
```

## Minting through the Binance Agentic Wallet

`baw` holds the key, so nothing here ever signs. The helper solves the challenge
for a wallet address and prints the two commands to run:

```bash
node scripts/mint-agent.js 0xYourAgentWallet --chain 56
```

```
baw contract-call preview --binanceChainId 56 --from <wallet> --to <nft> \
  --value 80000000000000 --inputData 0x… --json
baw contract-call execute --requestId <requestId from preview> --json
```

Developer Mode must be on (`baw wallet settings --json` → `devMode.enabled`).
The mint page's **Agent mode** panel prints the same pair for copy-paste.

## Challenge difficulty

Solving cost is `2^bits` keccak hashes. Measured: **~26,000 H/s** for the browser
worker, ~87,000 H/s for the Node solver (`@noble/hashes`).

| bits | mean hashes | desktop | phone (rough) |
|---|---|---|---|
| 16 | 65k | ~2-5 s | ~10 s |
| 18 | 262k | ~10 s | ~40 s |
| 20 (contract default) | 1.05M | ~40 s | ~2-4 min |

`scripts/deploy.js` ships **16 bits**. Raise it with
`DIFFICULTY_BITS=18 npm run deploy:mainnet`, or later via
`nft.setDifficultyBits(18)` (owner only, 8..32).

## Notes

- Metadata is fully on-chain: `tokenURI` returns base64 JSON wrapping a base64
  SVG derived from the token id. No IPFS, no gateway, nothing to pin.
- The contracts are compiled with `evmVersion: "cancun"` because OpenZeppelin v5
  utils use `MCOPY`; BSC supports Cancun since the Feynman upgrade.
- The marketplace escrows the NFT; `feeBps` is 0 so the seller receives the full
  price.
