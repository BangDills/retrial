# SPEC — Retrial: challenge-gated NFT mint + marketplace (BSC)

Repo root: `/root/retrial`. Node 26 + npm 11 available. Chain target: BNB Smart Chain
(mainnet chainId 56, testnet 97). Everything must be verifiable locally first.

## Product rules (from the owner, do not change)

1. Mint page headline price says **FREE (gas only)**.
2. The actual minting fee is **0.00008 BNB + gas** — it must be charged on chain and shown
   in the fee detail table (headline stays "FREE").
3. Total supply **3000** NFTs, hard cap.
4. Every mint requires solving a **challenge**; solving it entitles the solver to mint
   **1 NFT**.
5. Minted NFTs can be **listed and traded on a marketplace**.

## Architecture decisions (already made — implement as specified)

- The challenge is a **proof of work verified on chain**, so no backend and no signing key
  are needed and the gate cannot be bypassed by calling the contract directly:
  - `powValid(minter, nonce, bits)` ⇔ `uint256(keccak256(abi.encodePacked(minter, nonce)))`
    has at least `bits` leading zero bits, i.e. `h < (2**256 >> bits)`.
  - One keccak per verification ⇒ cheap on chain.
- Frontend is a **static site** (no server, no build step): plain HTML + ethers v6 UMD +
  a Web Worker for the solver. It must also render an "Agent mode" panel that prints the
  exact `baw contract-call preview/execute` command for the Binance Agentic Wallet CLI.
- Contracts use OpenZeppelin v5. Solidity ^0.8.24, optimizer on, `evmVersion` default.

## RetrialNFT.sol — required behaviour

ERC-721, name `Retrial`, symbol `RTR`, tokenIds start at 1.

Constants / state:
- `uint256 public constant MAX_SUPPLY = 3000;`
- `uint256 public constant MINT_FEE = 0.00008 ether;` (80_000_000_000_000 wei)
- `uint256 public difficultyBits = 20;` (owner-settable, must stay within 8..32)
- `uint256 public maxPerWallet = 5;` (owner-settable)
- `mapping(address => uint256) public mintedBy;`
- `mapping(address => mapping(uint256 => bool)) public usedNonce;`
- `uint256 public totalMinted;` (== `totalSupply` of ERC721; keep one source of truth)

`function mint(uint256 nonce) external payable` must:
- revert if `totalMinted >= MAX_SUPPLY`
- revert if `msg.value != MINT_FEE`  (exact, not `>=`)
- revert if `mintedBy[msg.sender] >= maxPerWallet`
- revert if `usedNonce[msg.sender][nonce]`
- revert if `!powValid(msg.sender, nonce, difficultyBits)`
- mark the nonce used, increment counters, mint the next tokenId to `msg.sender`
- emit `Minted(address indexed minter, uint256 indexed tokenId, uint256 nonce, uint256 difficultyBits)`

Also required:
- `function powValid(address minter, uint256 nonce, uint256 bits) public pure returns (bool)`
  so the frontend can pre-check and tests can grade a nonce.
- `function mintedCount() external view returns (uint256)` / `remaining()`
- `function withdraw(address to) external onlyOwner` sending the collected fees
- owner setters `setDifficultyBits`, `setMaxPerWallet` emitting events
- `tokenURI(uint256 tokenId)` → `data:application/json;base64,` JSON containing
  `name`, `description`, `attributes` (Challenge bits, Mint fee, Token id) and an
  `image` that is a `data:image/svg+xml;base64,` **on-chain generated SVG**. The SVG must
  be deterministic from `tokenId` (e.g. hue = tokenId * 137 mod 360) and contain the token
  id text so it is visibly unique per token. Use OZ `Strings` + `Base64`.

## RetrialMarket.sol — required behaviour

Escrow marketplace for RetrialNFT, priced in native BNB.

- `struct Listing { address seller; uint256 price; }`
- `mapping(uint256 => Listing) public listings;` + `uint256[] public listedIds` or a
  `activeListings()` view returning `(uint256[] ids, Listing[] data)` for the UI.
- `function list(uint256 tokenId, uint256 price) external` — caller must own the token,
  `price > 0`, contract must hold approval or use `transferFrom`; escrow the NFT into the
  market contract (`safeTransferFrom`), record the listing, emit `Listed`.
- `function updatePrice(uint256 tokenId, uint256 newPrice) external` — seller only.
- `function cancel(uint256 tokenId) external` — seller only, returns the NFT.
- `function buy(uint256 tokenId) external payable` — `msg.value == price`, pays the seller,
  transfers the NFT to the buyer, clears the listing, emits `Sold`.
- `uint256 public feeBps = 0;` with `setFeeBps` (max 500) and `withdrawFees` — default 0 so
  the seller receives the full price.
- Reentrancy-safe (OZ `ReentrancyGuard`, checks-effects-interactions, pull-payment not
  required but transfers must not be re-entrant).
- Constructor takes the RetrialNFT address.

## Tests (hardhat + chai, must all pass with `npx hardhat test`)

RetrialNFT:
1. metadata: name/symbol/MAX_SUPPLY/MINT_FEE/maxPerWallet/difficultyBits defaults
2. a JS solver finds a valid nonce for `difficultyBits` and `mint` succeeds with
   `value = MINT_FEE`; tokenId == 1; owner is the minter; `mintedBy` == 1; event emitted
3. `mint` with wrong value (0 and MINT_FEE-1) reverts
4. reusing the same nonce reverts
5. a nonce that does NOT satisfy the difficulty reverts (use `powValid` to pick a bad one)
6. per-wallet cap: after `maxPerWallet` mints the next reverts
7. supply cap: set `maxPerWallet` high, set difficulty low (e.g. 8) and assert the contract
   reverts once `totalMinted == MAX_SUPPLY` — do this without 3000 real mints, e.g. by
   asserting `mint` reverts when `totalMinted >= MAX_SUPPLY` using a helper that sets state
   through a small test-only subclass OR by setting MAX_SUPPLY via constructor arg (prefer:
   make `maxSupply` a constructor parameter defaulting to 3000, with a public getter named
   `MAX_SUPPLY()` returning it — keep the public API name `MAX_SUPPLY`)
8. `tokenURI` returns a data URI that base64-decodes to JSON with an `image` SVG containing
   the token id
9. `withdraw` pays the owner and reverts for non-owner

RetrialMarket:
10. list requires ownership and price > 0; escrows the NFT
11. buy with the exact price transfers the NFT and pays the seller; wrong value reverts
12. cancel returns the NFT; non-seller cannot cancel or updatePrice
13. buying a non-listed token reverts
14. `activeListings()` reflects list/cancel/buy

## scripts/deploy.js

- Reads `PRIVATE_KEY` (and optional `BSC_RPC_URL`, `BSC_TESTNET_RPC_URL`) from env or `.env`.
- Deploys `RetrialNFT(maxSupply)` then `RetrialMarket(nft)`.
- Writes `web/config.js` with `window.RETRIAL_CONFIG = { chainId, chainName, rpcUrl,
  nftAddress, marketAddress, explorer }`.
- Prints a table of addresses + the deploy tx hashes.

## scripts/mint-agent.js

Host-side helper for the Binance Agentic Wallet path:
- Reads the NFT address from `web/config.js` or `NFT_ADDRESS`.
- Solves the PoW for a given wallet address + difficulty (read from the contract via RPC).
- Encodes `mint(uint256)` calldata with ethers v6.
- Prints the ready-to-run command:
  `baw contract-call preview --binanceChainId 97 --from <wallet> --to <nft> --value 80000000000000 --inputData 0x... --json`
  and the matching `execute` line. Must NOT sign or send anything itself.

## Frontend requirements

`web/index.html` (mint page):
- Header with collection name + "FREE (gas only)" headline price.
- Stats row: `minted / 3000`, remaining, difficulty bits, your mints (`mintedBy(you)`) / cap.
- Fee detail table: Mint price **0.00008 BNB**, gas estimate, total. Headline stays FREE.
- Buttons: `Connect Wallet` (EIP-1193 `eth_requestAccounts`, chain check + `wallet_switchEthereumChain` for BSC 56/97), `Solve Challenge` (starts the worker, shows live hashrate and
  attempts), `Mint` (disabled until a valid nonce is found; sends `mint(nonce)` with
  `value = MINT_FEE`).
- After a successful mint: show the token id from the receipt's `Transfer` log and render
  the SVG from `tokenURI` inline.
- "Agent mode (Binance Agentic Wallet)" panel: input for the wallet address, a
  `Generate BAW command` button that solves the PoW and prints the exact
  `baw contract-call preview ... --json` / `execute` pair in a copyable `<pre>`.
- Must work as plain files (`file://` too) — no bundler, no imports; use the ethers UMD
  bundle from a CDN with a local fallback note.

`web/market.html`:
- Reads `activeListings()`, renders a card per listing (SVG image from `tokenURI`, token id,
  price, seller).
- `Buy` button → `buy(tokenId)` with `value = price`.
- "My NFTs" section: for each token the connected wallet owns, a `List for sale` form
  (approve + list) and, for own listings, `Cancel` / `Update price`.

`web/solver-worker.js`:
- `postMessage` protocol: in `{address, difficultyBits}`, out `{type:'progress', hashes,
  hashrate}` every ~200ms and `{type:'solved', nonce}`.
- Implements keccak256 over `abi.encodePacked(address, nonce)` (20 + 32 bytes) exactly like
  the contract: `ethers.keccak256(ethers.concat([address, ethers.zeroPadValue(hexNonce,32)]))`.
  Use ethers in the worker via `importScripts` of the same CDN bundle.
- Correctness matters more than speed: it must be verifiable against the contract's
  `powValid`. Include a `--selftest` style check in the page (compare the first found nonce
  against `powValid` via a read call before enabling Mint).
